# deep-tech-interview

A Codex skill for rapidly learning a technology deeply enough for advanced
interviews, production troubleshooting, and technical tradeoff discussions.

## Why

Most tutorials optimize for introduction, not interview depth. This skill
converts a topic into a question map, drives evidence-based learning, validates
at the right depth, compares alternatives, and pressure-tests your explanation
before you face real interview follow-ups.

## Install

Copy or clone this folder into your Codex skills directory:

```bash
mkdir -p ~/.codex/skills
cp -R deep-tech-interview ~/.codex/skills/
```

Then invoke it in Codex with:

```text
/deep-tech-interview
```

Or ask for interview-depth learning of a technology and let Codex discover the
skill.

## Usage

Say, for example:

```text
Use deep-tech-interview to help me learn LangGraph at interview depth.
```

Codex will guide the workflow in `references/METHOD.md`:

1. Self-assessment
2. Scope definition
3. Question map and scorecard
4. Question-driven absorption and cross-validation
5. Validation design and graded verification
6. Comparable-technology tradeoff analysis
7. Production notes
8. Pressure-tested output
9. Spaced review

## Files

- `SKILL.md`: Codex skill entry point.
- `references/METHOD.md`: complete method, templates, rubrics, and exit criteria.
